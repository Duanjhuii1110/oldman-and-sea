# 《老人与海：大海之上的不屈灵魂》

名著介绍视频 · AI 创作作品展示页。

基于海明威《老人与海》原著，拆解 8 个剧情分镜，逐段生成配图、旁白与提示词，最终合成一支 68 秒的名著讲解短片。

## 目录结构

```
oldman-and-sea/
├── index.html                     展示页面（单文件，样式内联）
├── README.md
└── assets/
    ├── images/
    │   ├── scene01.jpg            分镜 01 渔村老人
    │   ├── scene02.jpg            分镜 02 独自出海
    │   ├── scene03.jpg            分镜 03 鱼线悸动
    │   ├── scene04.jpg            分镜 04 海上对峙
    │   ├── scene05.jpg            分镜 05 征服大鱼
    │   ├── scene06.jpg            分镜 06 鲨鱼突袭
    │   ├── scene07.jpg            分镜 07 归途残骨
    │   └── scene08.jpg            分镜 08 不屈之心
    └── video/
        └── oldman-and-sea.mp4     成片（67 秒 / 1920×1080 / H.264）
```

## 本地预览

直接用浏览器打开 `index.html` 即可。

如果想用本地服务器预览（更接近线上环境），在本目录下执行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 页面结构

| 板块 | 内容 |
|---|---|
| 首屏 | 标题、项目简介、规格标签（书名 / 画幅 / 时长 / 分辨率 / 段落） |
| 01 / WORK | 成片播放器 + 制作规格表 + 统一画风说明 |
| 02 / STORYBOARD | 八段分镜网格（配图 + 段落名 + 剧情描述） |
| 03 / PROMPTS | 每段分镜的正向 / 负面 / 动态镜头提示词 |
| 04 / PIPELINE | 从原著到成片的七个制作步骤 |
| 05 / NOTES | 踩坑记录 |
| 06 / ABOUT | 页面说明与制作方式 |

## 素材说明

所有分镜配图、旁白、视频均由 AI 生成，用于课程作品展示。
